# Federated EEG Working Memory

## Project overview
This repository investigates federated learning for EEG-based working-memory decoding, with attention to differences between participants and non-IID data. The current work is **Phase 2: data acquisition, validation, preprocessing design, and exploratory analysis**. Model training is a later phase.

## Dataset
- Dataset: OpenNeuro `ds003655`, task `VerbalWorkingMemory`
- Source: https://openneuro.org/datasets/ds003655
- Downloaded participants currently audited: `sub-001`, `sub-002`
- Data format: EEGLAB `.set` + paired `.fdt`, BIDS events/channels/EEG JSON metadata
- Sampling rate: 500 Hz
- Channels: 19 EEG + 2 EOG
- Each participant has 120 task trials (20 per condition): `5R`, `6R`, `7R`, `5M`, `6M`, `7M`
- Raw EEG is excluded from Git because of its size and licensing/data-management considerations. See `.gitignore`.

## Data-centric cleaning and feature strategy
- Preserve raw files unchanged; keep raw data out of Git.
- Validate required files, sampling rate, channels, event timing, trial counts, missing stages, and ambiguous response mappings.
- Do not delete duplicate-looking response markers or impute missing EEG samples automatically.
- Event/trial audit: 240 probe/trial rows across two participants; the latest probe-based response audit marked 225 PASS and 15 REVIEW. This is a structural audit, not proof that every response is correctly attributed.
- A sustained repeated lower boundary around -10,239.69 µV was observed in all channels of `sub-001` near 332.5–333.5 s. The cause is not confirmed. Do not finalize amplitude cleaning, reject this participant, or scale the signal until the source/data representation has been investigated.
- Continuous EEG is not treated as a table of ordinary numeric outliers. Signal artifacts should be flagged and reviewed, not blindly clipped or winsorized.
- Trial-level numeric features, once extracted, should be standardized using parameters fit on training data only. For federated experiments, keep the local-vs-global scaling choice explicit and identical across experimental comparisons.
- Encode condition labels as categorical variables. Keep response labels and confidence/quality flags separate.

## Current limitations / next steps
